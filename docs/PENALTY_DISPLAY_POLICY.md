## 二、分層顯示策略

| 時間範圍 | 顯示方式 |
|---------|---------|
| 近 3 年 | 完整顯示（日期、項目、金額、法條、原連結） |
| 3–5 年 | 摘要顯示（「曾受 N 次處分」+ 折疊式列表） |
| 5 年以上 | 預設不顯示（內部仍保留） |
| 重大違規 | **永久顯示**，不論時間 |

### 「重大違規」明確定義

```
✅ 永久顯示條件（任一即適用）：
1. 違反醫療法第 28 條（密醫 / 非醫師執行醫療業務）
2. 造成病患死亡或重傷的醫療事故處分
3. 停業處分（不論天數）
4. 醫療機構或醫師證書廢止 / 註銷
5. 違反人體試驗管理辦法
```

## 四、嚴重度分級規則

| 分級 | 判定條件 |
|------|---------|
| 🔴 **重大** | 停業 / 廢止證書 / 致死致傷 / 密醫 / 人體試驗違規 |
| 🟡 **中度** | 罰款 ≥ NT$ 100,000，或單一年度受罰 ≥ 3 次 |
| 🟢 **輕微** | 罰款 < NT$ 50,000，或單純廣告 / 標示類違規 |

中間值（5 萬 ≤ 罰款 < 10 萬）依違規類型判定，預設為 🟡 中度。

## 六、診所申訴機制

診所後台 `/portal/[id]/penalties`：
- 列出該診所所有處分紀錄
- 每筆可上傳「改善說明」（200 字內）
- 改善說明顯示在處分記錄下方，標示「診所回應」字樣
- 若處分有重大爭議（如資料錯誤）可申請隱藏，進入 Admin 審核

審核 SLA：5 個工作天

---

## 七、法律免責設計

```
1. 每筆處分附公告原連結（衛福部、衛生局、公平會）
2. 平台底部聲明：「本頁資料來自政府公開資料，內容以原始公告為準」
3. /rules/penalty 公開政策頁
4. 不對處分內容做事實判斷，僅呈現公開資訊
5. 提供診所回應管道
```

## 八、評分公式（行政處分維度）

```
Penalty Score = 100 - 加總扣分
扣分規則：
  🔴 重大違規：每筆 -25 分（不衰減）
  🟡 中度違規：每筆 -10 分（衰減）
  🟢 輕微違規：每筆 -3 分（衰減）

時間衰減：
  近 1 年    ×1.0
  1-2 年    ×0.7
  2-3 年    ×0.4
  3-5 年    ×0.2
  5 年以上  ×0（不計入，但重大違規例外）

Cap 在 0 ~ 100
無紀錄 = 100 分
```
