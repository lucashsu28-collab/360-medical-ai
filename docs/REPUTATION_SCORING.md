# 360 醫美 AI 大調查 — 口碑評分規則
> 最後更新：2026-05-10
> 版本：v1.0

本文件定義「網路媒體口碑」與「社群口碑」兩維度的評分公式，公開透明、可被質疑、可申訴。

---

## 一、共通設計原則

```
基準分：60 分（無資料 = 中性，不偏袒不打壓）
範圍：0 ~ 100
更新頻率：每日重算
資料區間：採近 12 個月
4 大加權因子：情緒 × 來源 × 真實度 × 新鮮度
```

---

## 二、網路媒體口碑（News Score）

### 公式

```
News Score = 60 + Σ(每篇文章貢獻值)
每篇貢獻 = 情緒分 × 媒體權威 × 業配折扣 × 時間衰減 × 5
最終 cap 在 0 ~ 100
```

### 因子 1：情緒分（Gemini 2.5 Flash 判讀）

| 內容類型 | 分數 |
|---------|------|
| 強正面（名醫專訪、得獎） | +1.0 |
| 正面（一般推薦報導） | +0.5 |
| 中性（純資訊、新聞快報） | 0 |
| 負面（消費者投訴、警告） | -0.5 |
| 強負面（醫療事故、訴訟） | -1.0 |

### 因子 2：媒體權威度

| 等級 | 媒體 | 權重 |
|------|------|------|
| A 級 主流媒體 | 蘋果、聯合、自由、中時、TVBS、鏡週刊 | ×1.5 |
| B 級 網路媒體 | ETtoday、三立、東森、Yahoo | ×1.2 |
| C 級 醫美專業 | 醫美時尚、姊妹淘、Beauty 美人圈 | ×1.0 |
| D 級 內容農場 / 不知名 | 自動辨識（網域信譽資料庫） | ×0.5 |

### 因子 3：業配折扣

| 判定 | 權重 | 辨識規則 |
|------|------|---------|
| 純編輯內容 | ×1.0 | 無業配特徵 |
| 疑似業配 | ×0.3 | 含「合作刊登」「廣編」「廠商提供」等關鍵詞 |

### 因子 4：時間衰減

| 時間 | 權重 |
|------|------|
| 近 3 個月 | ×1.0 |
| 3–6 個月 | ×0.7 |
| 6–12 個月 | ×0.4 |
| 12 個月以上 | 不計入 |

### 重大事件加重規則

```
醫療事故報導（造成傷亡）：單篇 -20 分（不受時間衰減保護）
訴訟敗訴報導：單篇 -10 分
得獎/權威認證報導：單篇 +5 分
```

### 範例試算

A 診所近 3 個月：
- 蘋果日報正面報導 1 篇：+0.5 × 1.5 × 1.0 × 1.0 × 5 = **+3.75**
- ETtoday 業配 1 篇：+0.5 × 1.2 × 0.3 × 1.0 × 5 = **+0.90**
- Yahoo 負面消費爭議 1 篇：-0.5 × 1.2 × 1.0 × 1.0 × 5 = **-3.00**

**News Score = 60 + 3.75 + 0.90 - 3.00 = 61.65 → 62 分**

## 三、社群口碑（Social Score）

### 公式

```
Social Score = 60 + Σ(每篇貼文貢獻值)
每篇貢獻 = 情緒分 × 平台權重 × 互動權重 × 業配折扣 × 時間衰減 × 5
最終 cap 在 0 ~ 100
```

### 因子 1：情緒分（同新聞）

`-1.0 ~ +1.0`

### 因子 2：平台權重

| 平台 | 權重 | 理由 |
|------|------|------|
| PTT MakeUp / BeautySalon | ×1.5 | 老用戶集中、討論深度高、難以操作 |
| Dcard 美容板 / 整形板 | ×1.3 | 匿名真實、互動量大 |
| Mobile01 美容時尚 | ×1.0 | 中年女性主力 |
| 痞客邦 / 部落格 | ×0.7 | 業配比例高 |

### 因子 3：互動權重（社群獨有）

| 互動程度 | 標準 | 權重 |
|---------|------|------|
| 高互動 | 留言 ≥ 50 或推 ≥ 100 | ×1.3 |
| 中互動 | 留言 10–49 | ×1.0 |
| 低互動 | 留言 < 10 | ×0.6 |
| 噓爆文（PTT 限定） | 噓 > 推 × 2 | ×1.5（負面加重） |

### 因子 4：業配折扣

| 判定 | 權重 |
|------|------|
| 真實心得（無業配特徵） | ×1.0 |
| 疑似業配（含 #合作 #體驗 等） | ×0.3 |
| 確認業配（有明顯廠商連結 / 折扣碼） | ×0.1 |

### 因子 5：時間衰減（同新聞）

### 範例試算

B 診所近 3 個月：
- Dcard 美容板正面心得（80 留言）：+0.5 × 1.3 × 1.3 × 1.0 × 1.0 × 5 = **+4.23**
- PTT MakeUp 噓爆負評（50 噓）：-1.0 × 1.5 × 1.5 × 1.0 × 1.0 × 5 = **-11.25**
- 痞客邦業配文：+1.0 × 0.7 × 0.6 × 0.1 × 1.0 × 5 = **+0.21**

**Social Score = 60 + 4.23 - 11.25 + 0.21 = 53.19 → 53 分**

## 四、評分等級對照

| 分數 | 等級 | 標籤 |
|------|------|------|
| 90–100 | S | 🌟 口碑卓越 |
| 80–89 | A | ⭐ 口碑優良 |
| 70–79 | B | ✓ 口碑良好 |
| 60–69 | C | ➖ 口碑中性 |
| 50–59 | D | ⚠️ 口碑普通 |
| 0–49 | E | 🔴 口碑警示 |

## 五、防作弊設計

```
1. 同來源同診所 24 小時內僅計第一篇（防灌水）
2. 單篇權重上限 ±5 分（防極端）
3. 互動數據抓取後 24 小時內凍結（防即時操作）
4. 新建立帳號 / 低聲望帳號發文 ×0.5（PTT/Dcard 適用）
5. 短時間爆量負評 → 觸發人工審核（防黑公關）
6. IP/帳號集中度檢測：同 IP 多帳號發相似內容 → 全部排除
```

## 六、申訴機制

診所後台可對單篇來源提出異議：
- 「這不是業配」→ 進入人工複核（5 個工作天）
- 「報導不實」→ 附證據申請隱藏
- 「已和解/已改善」→ 不刪除原文，但可附「診所回應」

申訴流程：
```
診所提交異議 → Admin 審核中心 → 採納/駁回 → 發送通知 → 重算分數
```
