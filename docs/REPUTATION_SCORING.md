# 360 醫美 AI 大調查 — 媒體口碑評分規則
> 最後更新：2026-05-10
> 版本：v2.0（社群口碑下線、合併為單一媒體口碑維度）

本文件定義「媒體口碑」第 5 維度的評分公式。

---

## 一、五維度評鑑體系

| # | 維度 | 滿分 | 資料來源 |
|---|------|------|---------|
| 1 | 司法糾紛 | 20 | 司法院裁判書 |
| 2 | Google 評分 | 20 | Google Places |
| 3 | 合法登記 | 20 | 衛福部 |
| 4 | 稽查違規紀錄 | 20 | 政府公開資料 + 媒體報導（見 PENALTY_DISPLAY_POLICY.md） |
| 5 | **媒體口碑** | 20 | 主流媒體報導（本文件） |

**總分 = 各維度貢獻加總，滿分 100**

---

## 二、為何下線社群口碑

社群匿名討論（PTT/Dcard/論壇）原本是第 6 維度，2026-05-10 下線，理由：

| 客觀性問題 | 影響 |
|-----------|------|
| 匿名易被操作 | 水軍 push、競爭對手黑公關 |
| 業配充斥 | AI 過濾仍會漏網 |
| 流量結構性下降 | 年輕人轉去 IG/TikTok（API 鎖死抓不到） |
| 抓取覆蓋率低 | Dcard/Mobile01 反爬，PTT 萎縮 |
| 法律風險高 | 匿名負評爭議，平台難舉證 |

**社群熱議其實已被新聞媒體吸收**——爆紅文章會被 ETtoday/Yahoo 等收編，等於 Google News 已篩過一次「值得報導」的內容。保留社群維度有 80% 是冗餘資料。

> 後端爬蟲程式 `crawlers/social_mentions.py` 保留但不執行，未來如果接到 IG/TikTok 認證 API 或第三方付費社群監測，可立即啟用。

## 三、媒體口碑公式

```
媒體口碑分數 = 60 + Σ(每篇文章貢獻值)
每篇貢獻 = 情緒分 × 媒體權威 × 業配折扣 × 時間衰減 × 5
最終 cap 在 0 ~ 100

對總分貢獻 = (媒體口碑分數 / 100) × 20

基準分：60（無資料 = 中性，不偏袒不打壓）
資料區間：近 12 個月
更新頻率：每週日 04:00（Cloud Scheduler `news-mentions-update`）
```

### 因子 1：情緒分（Gemini 2.5 Flash 判讀）

| 內容類型 | 分數 |
|---------|------|
| 強正面（名醫專訪、得獎） | +1.0 |
| 正面（一般推薦報導） | +0.5 |
| 中性（純資訊、新聞快報） | 0 |
| 負面（消費者投訴、警告） | -0.5 |
| 強負面（醫療事故、訴訟） | -1.0 |

### 因子 2：媒體權威度

| 等級 | 媒體 | 權重 |
|------|------|------|
| A 級 主流媒體 | 蘋果、聯合、自由、中時、TVBS、鏡週刊 | ×1.5 |
| B 級 網路媒體 | ETtoday、三立、東森、Yahoo、風傳媒、新頭殼、NOWnews | ×1.2 |
| C 級 醫美專業 | 醫美時尚、姊妹淘、Beauty 美人圈、ELLE、美麗佳人 | ×1.0 |
| D 級 內容農場 / 不知名 | 自動辨識 | ×0.5 |

### 因子 3：業配折扣

| 判定 | 權重 | 辨識規則 |
|------|------|---------|
| 純編輯內容 | ×1.0 | 無業配特徵 |
| 疑似業配 | ×0.3 | 含「合作刊登」「廣編」「廠商提供」等關鍵詞 |
| 確認業配 | ×0.1 | Gemini 高信心 + 多項業配特徵 |

### 因子 4：時間衰減

| 時間 | 權重 |
|------|------|
| 近 3 個月 | ×1.0 |
| 3–6 個月 | ×0.7 |
| 6–12 個月 | ×0.4 |
| 12 個月以上 | 不計入 |

### 重大事件加重規則

```
醫療事故報導（造成傷亡）：單篇 -20 分（不受時間衰減保護）
訴訟敗訴報導：單篇 -10 分
得獎/權威認證報導：單篇 +5 分
```

### 範例試算

A 診所近 3 個月：
- 蘋果日報正面報導 1 篇：+0.5 × 1.5 × 1.0 × 1.0 × 5 = **+3.75**
- ETtoday 業配 1 篇：+0.5 × 1.2 × 0.3 × 1.0 × 5 = **+0.90**
- Yahoo 負面消費爭議 1 篇：-0.5 × 1.2 × 1.0 × 1.0 × 5 = **-3.00**

**媒體口碑分數 = 60 + 3.75 + 0.90 - 3.00 = 61.65 → 62 分**
**對總分貢獻 = 62 / 100 × 20 = 12.4 分**

## 四、評分等級對照

| 媒體口碑分數 | 等級 | 標籤 |
|------|------|------|
| 90–100 | S | 🌟 口碑卓越 |
| 80–89 | A | ⭐ 口碑優良 |
| 70–79 | B | ✓ 口碑良好 |
| 60–69 | C | ➖ 口碑中性 |
| 50–59 | D | ⚠️ 口碑普通 |
| 0–49 | E | 🔴 口碑警示 |

## 五、防作弊設計

```
1. 同來源同診所 24 小時內僅計第一篇（防灌水）
2. 單篇權重上限 ±5 分（防極端，重大事件除外）
3. D 級媒體權重折半，避免內容農場操作
4. 業配辨識雙軌：關鍵字 + Gemini AI
5. 短時間爆量負評 → 觸發人工審核（防黑公關）
```

---

## 六、申訴機制

診所後台 `/portal/[id]/penalties` 可對單篇來源提出異議：
- 「這不是業配」→ 進入人工複核（5 個工作天）
- 「報導不實」→ 附證據申請隱藏
- 「已和解/已改善」→ 不刪除原文，但可附「診所回應」
